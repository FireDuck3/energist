# Етап 2: геолокація, пошук, фільтри, кластеризація — дизайн

## Мета
Дати гостю швидко знайти потрібну зарядку: поруч, з потрібним роз'ємом і потужністю — і на приватних точках, і на публічних станціях.

## Цілі
- Геолокація лише за дозволом користувача, натисненням кнопки «📍 Моє місце». Координати не зберігаються й нікуди не надсилаються (живуть у пам'яті сторінки).
- Радіус 1/5/10/25/50 км (доступний, коли відоме місцеположення), сортування списку за відстанню, відстань у картках.
- Фільтри: роз'єм (Type 2, CCS2, CHAdeMO, GB/T, Інший; мультивибір), потужність (до 22 / 22–50 / 50–150 / понад 150 кВт), ціна, «Працює цілодобово», «Доступна під час блекауту».
- Кластеризація маркерів публічних станцій (leaflet.markercluster 1.5.3, зафіксована версія з unpkg; без бібліотеки — звичайні маркери).
- Перемикач «Карта / Список».
- Кнопка «Знайти найближчу зарядку»: бере найближчу з відфільтрованих (приватні, демо при увімкненому режимі й публічні), центрує карту й відкриває її popup.

## Не цілі
Автозастосування типу авто з профілю гостя (Етап 3–4, кабінет гостя), збереження фільтрів в акаунті, прокладання власного маршруту в застосунку (лишається посилання), статуси в реальному часі.

## Правила (рішення, що впливають на результат)
- **Ціна:** фільтр діє на публічну станцію лише коли ціна обмежена (менше 25 грн); станція без `price_verified` тоді не показується. Без обмеження — показуються всі.
- **Роз'єми приватних/демо точок:** `type2` → Type 2, `socket220` і `usb` → «Інший».
- **Потужність:** `powerKw` точки / `max_power_kw` станції; невідома потужність не проходить фільтр потужності.
- **Цілодобово:** станція — `opening_hours === 'Цілодобово'`; точка — графік 00:00–24:00.
- **Блекаут:** публічні станції не мають підтвердженої автономності, тому фільтр «Доступна під час блекауту» їх ховає; для точок — наявна логіка (`source !== 'grid'`). Глобальний перемикач ⚡ Блекаут лишається як є.
- Без місцеположення радіус неактивний (чипи вимкнено з підказкою), кнопка «Знайти найближчу» спершу просить дозвіл.
- Відмова/помилка геолокації — зрозуміле повідомлення, карта працює як раніше.

## Підходи
1. **Чисті функції в новому `js/map-filters.js` + підключення в `map.js` (обрано).** Тестується в браузерному ранері без DOM; `map.js` лише малює.
2. Розширити `filters.js`/`map.js` без нового модуля — робить `map.js` (вже 300+ рядків) ще важчим; відкинуто.

## Дизайн
- `js/map-filters.js`: `distanceKm(a,b)`, `POWER_BANDS`, `RADII = [1,5,10,25,50]`, `spotConnector(spot)`, `matchStation(st, f, {origin, blackout})`, `matchSpotExtra(spot, f, {origin})`, `sortByDistance(items, origin)`, `nearest(items, origin)`. Розширення `DEFAULT_FILTERS` у `filters.js`: `connectors: []`, `power: null`, `radiusKm: null`, `only24h: false`, `blackoutReady: false`.
- `js/geolocate.js`: `locate({geolocation = navigator.geolocation}) → Promise<{lat,lng}>` з чіткими помилками (`denied`, `unavailable`, `timeout`).
- `map.js`: нові ряди фільтрів, кнопки «Моє місце» й «Знайти найближчу», перемикач «Карта/Список», кластерний шар станцій, відстань у картках, список станцій відфільтрований і відсортований (замість «перших 50»); повертається екран «Нічого не знайдено» (відкладений мінор Етапу 1), правильне відмінювання «станцій», перепідгін карти при зміні набору.
- CSS для нових елементів і режимів `view-map` / `view-list`.
- Тести: `tests/map-filters.test.js`, `tests/geolocate.test.js` (+ оновлення `store`/`filters` тестів за потреби).
