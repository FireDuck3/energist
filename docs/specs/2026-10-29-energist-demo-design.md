# ЕнерГість — демо-вебапка для пітчу

Дата: 2026-10-29
Джерело ідеї: презентація `ЕнерГість.pptx` (6 слайдів)

## 1. Мета

Клікабельне демо P2P-маркетплейсу електрики «ЕнерГість» («енергетичний Airbnb / EnergyUber») для пітчу.
Демо має за 3–5 хвилин показати журі, що продукт розв'язує обидві сторони проблеми з презентації:

- **Саша** (гість) живе в багатоповерхівці, має електромобіль або EcoFlow, не має доступу до розетки, комерційні зарядки коштують 30–40 грн/кВт·год.
- **Олег** (господар) має приватний будинок із СЕС, генерує понад потребу, домашній тариф 4,32 грн/кВт·год, зеленого тарифу немає, хоче окупити СЕС.

Успіх: на пітчі можна наживо пройти шлях Саші і шлях Олега, показати калькулятор вигоди й режим блекауту без збоїв і без пояснень «тут мало б бути…».

## 2. Що вирішено з користувачем

| Питання | Рішення |
|---|---|
| Призначення | Демо для пітчу, фейкові дані, без сервера |
| Пристрій показу | Десктопний сайт на весь екран (стиль Airbnb), адаптивний для телефону |
| Сценарії | Шлях Саші, шлях Олега, калькулятор вигоди, режим блекауту |
| Карта | Реальна карта Вінниці з вигаданими точками |
| Хостинг | GitHub Pages, репозиторій `energist` |
| Стек | Чистий HTML/CSS/JS (ES-модулі) + Leaflet, без збірки (Node.js на ноутбуці немає) |
| Комісія сервісу | 10% |

Припущення (не обговорювались окремо): мова інтерфейсу — лише українська; гроші — гривні; дата пітчу невідома, тому пріоритет — стабільність основних сценаріїв над дрібним шліфуванням.

## 3. Екрани

Хеш-маршрути (працюють на GitHub Pages без налаштувань сервера):

| Маршрут | Екран |
|---|---|
| `#/` | Головна (лендінг) |
| `#/map` | Карта + список точок (шлях Саші) |
| `#/spot/:id` | Картка точки |
| `#/host` | Кабінет господаря (шлях Олега) |
| `#/calc` | Калькулятор вигоди |

Бронювання — модалка поверх картки точки, не окремий маршрут.

**Шапка** на всіх екранах: логотип «ЕнерГість», перемикач ролі «Я шукаю зарядку» / «Я ділюсь енергією» (веде на `#/map` / `#/host`), посилання «Калькулятор», перемикач «⚡ Блекаут».
**Підвал:** кнопка «Скинути демо».

### 3.1 Головна `#/`
- Героїчний блок: ілюстрація будинку з СЕС (з презентації), заголовок «Енергетичний Airbnb для України», підзаголовок про P2P-маркетплейс, кнопки «Знайти розетку» → `#/map` і «Здати свою енергію» → `#/host`.
- Блок «Проблема»: дві короткі історії — Саша і Олег — з цифрами з презентації.
- «Як це працює»: 4 кроки — Пошук → Бронювання → Зарядка → Оплата.
- Компактна версія калькулятора вигоди (повна — на `#/calc`).

### 3.2 Карта `#/map`
- Ліворуч список карток точок, праворуч карта Вінниці (Leaflet).
- Фільтри над списком: пристрій (Електромобіль / EcoFlow / Телефон-ноутбук), максимальна ціна (повзунок), мінімальний рейтинг, «Доступно зараз».
- Наведення на картку в списку підсвічує пін, і навпаки. Клік — `#/spot/:id`.
- Лічильник «Знайдено N точок».

### 3.3 Картка точки `#/spot/:id`
- Фото/ілюстрація, назва, район, господар (ім'я, рейтинг, кількість зарядок).
- Джерело енергії (☀️ СЕС / 🔋 батарея / ⚡ мережа), потужність у кВт, тип підключення, сумісні пристрої, ціна за кВт·год, графік доступності.
- Відгуки.
- Блок порівняння: «Тут 12 грн/кВт·год · комерційна зарядка ~35 грн».
- Кнопка «Забронювати» → модалка бронювання.

### 3.4 Модалка бронювання (5 кроків)
1. **Час:** пристрій, день (сьогодні/завтра), слот початку з графіка господаря, тривалість 1–6 год. Показується очікувана кількість кВт·год і орієнтовна сума.
2. **Підтвердження:** зведення + «Гроші буде заморожено до завершення зарядки (безпечна угода)». Кнопка «Підтвердити і заморозити N грн».
3. **Зарядка (симуляція):** анімована батарея, лічильник кВт·год і гривень наживо, симульований час «0:45 / 2:00». Уся сесія триває ~20 секунд реального часу незалежно від тривалості. Кнопка «Завершити раніше».
4. **Оплата:** фактичні кВт·год, сума, розбивка «Господарю N грн / Комісія ЕнерГість 10% — N грн», економія порівняно з комерційною зарядкою, повернення різниці із замороженої суми. Анімація галочки.
5. **Відгук:** 1–5 зірок + текст. Відгук одразу з'являється на картці точки, рейтинг перераховується.

### 3.5 Кабінет господаря `#/host`
Демо-акаунт Олега (Вишенька, СЕС 10 кВт).
- Зведення: заробіток за місяць, кількість зарядок, рейтинг, продано кВт·год.
- Графік заробітку за останні 6 місяців (стовпчики) + «Окупність СЕС: N%» (прогрес-бар від умовної вартості СЕС).
- Список бронювань: засіяні (частина зі статусом «очікує підтвердження» з кнопками Підтвердити/Відхилити) + усі бронювання, які користувач зробив у ролі Саші на точках Олега.
- Мої точки + кнопка «Додати розетку»: форма з кліком по карті для координат, назва, тип підключення, потужність, джерело енергії, ціна за кВт·год (з підказкою діапазону 8–15), графік. Нова точка одразу з'являється на карті гостя.

### 3.6 Калькулятор `#/calc`
- Повзунки: «Скільки кВт·год на тиждень вам потрібно» (Саша) і «Скільки надлишку на місяць» (Олег), ціна ЕнерГостя (за замовчуванням 12).
- Результат: економія Саші за місяць порівняно з комерційною зарядкою; заробіток Олега за місяць (після комісії) порівняно з тим, що енергія пропадає/віддається мережі; дохід сервісу.
- Візуальна шкала цін: 4,32 (домашній тариф) — ціна ЕнерГостя — 30–40 (комерційна зарядка).

## 4. Режим блекауту

Перемикач у шапці. Коли увімкнено:
- Банер «У вашому районі немає світла з 14:00 (демо)».
- Тайли карти перемикаються на темні (CARTO Dark Matter), тема сторінки — темно-синя.
- Точки з джерелом СЕС або батарея лишаються яскравими з підписом «протримається ще ~N год» (`blackoutHours`).
- Точки з джерелом «мережа» стають сірими й некликабельними («немає світла»), у списку не показуються.

## 5. Архітектура і файли

```
energist/
  index.html            каркас, шрифт Inter (Google Fonts), Leaflet 1.9.4 з CDN
  css/styles.css        токени кольорів, компоненти, світла тема і тема блекауту
  js/app.js             точка входу: ініціалізація store, router, шапки
  js/data.js            точки, господарі, відгуки, засіяні бронювання, константи цін
  js/pricing.js         чисті функції розрахунків (див. §7)
  js/filters.js         чисті функції фільтрації точок (пристрій, ціна, рейтинг, блекаут)
  js/store.js           стан + підписки + збереження в localStorage + скидання
  js/router.js          хеш-маршрутизація
  js/ui.js              дрібні хелпери (форматування грн/кВт·год, модалка, тости)
  js/views/landing.js
  js/views/map.js
  js/views/spot.js
  js/views/booking.js
  js/views/host.js
  js/views/calculator.js
  assets/               ілюстрації з презентації, стиснені
  tests/index.html      тести pricing.js і filters.js у браузері
  docs/specs/           цей документ
```

Принципи:
- Ціни й константи — лише в `data.js`; розрахунки — лише в `pricing.js`. Тому цифри на всіх екранах збігаються.
- `pricing.js` і `filters.js` не торкаються DOM і стану — тестуються ізольовано.
- В'юшки читають стан зі `store`, змінюють його лише через функції `store`, перемальовуються за підпискою.
- Усі шляхи відносні (сайт живе за адресою `/energist/`).

## 6. Модель даних

**Spot (точка):**
`id`, `title`, `district`, `lat`, `lng`, `hostId`, `source` (`solar` | `battery` | `grid`), `powerKw`, `connector` (`type2` | `socket220` | `usb`), `devices` (масив з `ev`, `ecoflow`, `gadget`), `pricePerKwh`, `schedule` (`{ from: "08:00", to: "20:00" }`), `blackoutHours`, `image`, `reviews` (масив `{ author, stars, text, date }`).

**Host:** `id`, `name`, `avatar`, `chargesCount`, `sesCost` (для окупності).

**Booking:** `id`, `spotId`, `guestName`, `device`, `day`, `start`, `hours`, `estimatedKwh`, `heldAmount`, `status` (`pending` | `held` | `charging` | `paid` | `reviewed` | `declined`), `actualKwh`, `total`, `fee`, `hostPayout`, `createdAt`.

**Пристрої (ємність, яку можна залити за сесію):** `ev` — 40 кВт·год, `ecoflow` — 1 кВт·год, `gadget` — 0,1 кВт·год.

Засіяні дані: 14–16 точок по районах Вінниці (Центр, Вишенька, Замостя, Старе місто, Слов'янка, Тяжилів, П'ятничани, Академічний, Сабарів, Поділля), мікс джерел (≈50% СЕС, 25% батарея, 25% мережа), ціни 8–15 грн, рейтинги 4,3–5,0, 2–4 відгуки на точку; 4–6 засіяних бронювань у Олега.

## 7. Розрахунки (`pricing.js`)

Константи (`data.js`): `COMMISSION = 0.10`, `HOME_TARIFF = 4.32`, `COMMERCIAL_PRICE = 35` (діапазон 30–40 для шкали).

| Функція | Формула |
|---|---|
| `estimateKwh(powerKw, hours, device)` | `min(powerKw × hours, capacity[device])` |
| `holdAmount(kwh, price)` | `kwh × price` (округлення до копійок) |
| `sessionCost(kwh, price)` | `total = kwh × price`; `fee = total × COMMISSION`; `hostPayout = total − fee` |
| `savingsVsCommercial(kwh, price)` | `kwh × COMMERCIAL_PRICE − kwh × price` |
| `gridValue(kwh)` | `kwh × HOME_TARIFF` |
| `monthlyGuestSavings(kwhPerWeek, price)` | `savingsVsCommercial(kwhPerWeek × 4.33, price)` |
| `monthlyHostEarnings(kwhPerMonth, price)` | `sessionCost(kwhPerMonth, price).hostPayout` |

Еталонний приклад (обов'язковий тест): 30 кВт·год × 12 грн → `total = 360`, `fee = 36`, `hostPayout = 324`, економія = 1050 − 360 = 690, `gridValue = 129.6`.

Гроші округлюються до 2 знаків лише при поверненні з функції; відображаються як `360 грн` / `129,60 грн`.

## 8. Стан і збереження (`store.js`)

Стан: `role`, `blackout`, `filters`, `spots` (засіяні + додані), `bookings`, `reviews`-зміни.
Зберігається в `localStorage` під ключем `energist-demo-v1`. Кожне читання/запис у `try/catch`: якщо сховище недоступне — демо працює без збереження.
«Скинути демо» видаляє ключ і перезавантажує засіяні дані.

## 9. Вигляд

- Кольори (зі слайдів): фон `#F4F8FC`, небесний `#A7D2ED` / `#82B8DE`, індиго `#4950BC` (головні кнопки, активні стани), текст `#272525`, помаранчевий акцент `#F28C38` (СЕС-піни, «доступно зараз»), сонячний `#FFC94A`. Тема блекауту: фон `#141833`, картки `#1F2547`, текст `#E8ECF8`.
- Шрифт Inter.
- Тайли карти: CARTO Positron (світла) і Dark Matter (блекаут), з атрибуцією OSM/CARTO.
- Піни: круглі значки з іконкою джерела, колір за джерелом (СЕС — помаранчевий, батарея — індиго, мережа — сірий); обраний пін збільшується.
- Ілюстрації з презентації — на головній і в порожніх станах.
- Анімації стримані: наповнення батареї, лічильники, галочка після оплати.
- Без декоративних смуг і градієнтних бордюрів.

## 10. Збої на пітчі

- Тайли/Leaflet не завантажились → замість карти плашка «Карта недоступна — перевірте інтернет», список і всі сценарії працюють.
- `localStorage` недоступний → працює без збереження.
- Невідомий маршрут або `id` точки → редирект на `#/map`.

## 11. Тестування

- `tests/index.html` — мінімальний тест-ранер у браузері: еталонний приклад §7, `estimateKwh` для кожного пристрою, обрізання за ємністю, `filters.js` (пристрій, ціна, рейтинг, блекаут ховає `grid`).
- Ручна перевірка у вбудованому браузері: шлях Саші від карти до відгуку; шлях Олега з додаванням точки і появою її на карті; бронювання на точці Олега видно в його кабінеті; калькулятор; блекаут; «Скинути демо»; ширина 375 px.
- Локальний запуск: `python -m http.server 8000` у корені проєкту (ES-модулі не працюють з `file://`).

## 12. Деплой

1. Локальний git-репозиторій, коміти по ходу роботи.
2. Користувач створює порожній публічний репозиторій `energist` на github.com.
3. Пуш гілки `main` (лише після згоди користувача).
4. Settings → Pages → Deploy from branch → `main` / root.
5. Адреса: `https://fireduck3.github.io/energist/`.
